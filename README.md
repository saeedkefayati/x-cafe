# Cafe Commerce

پایهٔ فنی یک وب‌سایت فروشگاهی Premium و Editorial برای کافه، مطابق مستندات `cafe-commerce-pre-codex-pack`.

## شروع محلی

```bash
pnpm install
pnpm dev
```

## بررسی کیفیت

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

تم تصویری کاتالوگ تأیید شده و ۱۵ تصویر محصول در `public/images/products` قرار دارد. مشخصات مجموعه در manifest همان پوشه ثبت شده است.

نام نهایی برند، قیمت‌ها، شعبه‌ها، پرداخت و اطلاعات حقوقی فعلاً آزمایشی هستند و باید پیش از انتشار با اطلاعات واقعی جایگزین شوند. بستهٔ محلی `cafe-commerce-pre-codex-pack` فقط مرجع برنامه‌ریزی است و عمداً وارد Git نمی‌شود.
