# 15 — Acceptance Criteria

این فایل برای بررسی نهایی خروجی Codex است.

---

# Visual

- [ ] طراحی حس Premium / Minimal / Editorial دارد.
- [ ] سایت شبیه template عمومی ecommerce نیست.
- [ ] فضای خالی کافی وجود دارد.
- [ ] typography hierarchy واضح است.
- [ ] تصاویر تمام محصولات یک زبان بصری مشترک دارند.
- [ ] هیچ بخش مهمی به دلیل animation شلوغ نشده است.

---

# Navigation

- [ ] Desktop nav واضح است.
- [ ] Mobile nav کامل است.
- [ ] Search در دسترس است.
- [ ] Cart از تمام صفحات اصلی قابل دسترسی است.
- [ ] deep links درست کار می‌کنند.

---

# Home

- [ ] Hero قوی و سریع قابل فهم است.
- [ ] Product transformation smooth و purposeful است.
- [ ] Category discovery واضح است.
- [ ] Best Sellers بدون Motion اضافی قابل استفاده است.
- [ ] Brand story خوانا است.
- [ ] Location و Journal قابل پیدا کردن هستند.
- [ ] reduced-motion version کامل است.

---

# Menu

- [ ] category switching سریع است.
- [ ] product cards اطلاعات ضروری دارند.
- [ ] unavailable state واضح است.
- [ ] mobile layout طبیعی است.
- [ ] return navigation context منطقی است.

---

# Product Detail

- [ ] نام، قیمت و توضیح سریع دیده می‌شود.
- [ ] customization واضح است.
- [ ] price delta مشخص است.
- [ ] Add to Cart سریع است.
- [ ] motion مانع انتخاب options نیست.
- [ ] related products منطقی است.

---

# Cart

- [ ] add/remove/update quantity درست است.
- [ ] customization هر item حفظ می‌شود.
- [ ] subtotal درست است.
- [ ] drawer keyboard accessible است.
- [ ] empty state دارد.

---

# Checkout

- [ ] keyboard friendly
- [ ] validation clear
- [ ] error states clear
- [ ] loading state clear
- [ ] no unnecessary cinematic motion
- [ ] success state clear

---

# Accessibility

- [ ] semantic headings
- [ ] focus-visible
- [ ] keyboard navigation
- [ ] labels
- [ ] alt text
- [ ] reduced motion
- [ ] no color-only status
- [ ] accessible drawer/modal behavior

---

# Performance

- [ ] responsive images
- [ ] stable image aspect ratios
- [ ] no unnecessary huge assets
- [ ] animation cleanup
- [ ] no duplicate animation libraries
- [ ] mobile performance acceptable
- [ ] content functional if enhanced motion fails

---

# Responsive

- [ ] mobile is redesigned, not shrunk desktop
- [ ] touch targets usable
- [ ] no hover dependency
- [ ] pinned scenes degrade properly
- [ ] landscape mobile considered
- [ ] sticky CTA respects safe areas

---

# Content

- [ ] no lorem ipsum in production
- [ ] product descriptions concrete
- [ ] error/empty text exists
- [ ] SEO fields available
