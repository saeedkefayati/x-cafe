# Cafe Commerce — Pre-Coding Planning Pack

این بسته، تمام تصمیم‌های اصلی پروژه را قبل از شروع کدنویسی مشخص می‌کند تا اجرای پروژه در Codex تا جای ممکن «پیاده‌سازی بر اساس Spec» باشد، نه تصمیم‌گیری حین توسعه.

## هدف پروژه

ساخت یک وب‌سایت فروشگاهی بسیار حرفه‌ای برای کافه با ویژگی‌های زیر:

- تجربه‌ی بصری Premium و Minimal
- الهام از دقت، فضای خالی و Storytelling سایت‌های Apple، بدون کپی بصری
- هویت گرم، خوراکی، Crafted و انسانی مناسب یک برند کافه
- Scroll-driven storytelling در Home و Product Detail
- Page transitionهای نرم و هدفمند
- سیستم یکپارچه برای تولید تصاویر تمام آیتم‌های منو با ChatGPT Image
- UX سریع و کم‌حواس‌پرتی در Cart و Checkout
- معماری قابل توسعه برای Menu، Blog، Locations، Orders و امکانات آینده

## اصل راهنما

هر تصمیمی که روی معماری، تجربه، ظاهر، Motion، محتوا یا تصاویر اثر دارد باید قبل از کدنویسی مشخص شود.

Codex باید عمدتاً این کارها را انجام دهد:

- تبدیل Spec به ساختار پروژه
- ساخت کامپوننت‌ها و Routeها
- پیاده‌سازی Design Tokens
- پیاده‌سازی Motion
- پیاده‌سازی Data Models
- تست
- Refactor
- Performance tuning

Codex نباید بدون دلیل روشن تصمیم‌های اصلی Visual/UX را از خودش اختراع کند.
