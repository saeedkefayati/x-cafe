# 10 — Product Detail Storyboard

## هدف

Product Detail باید هم Storytelling داشته باشد، هم خرید را سریع نگه دارد.

---

# Entry Transition

از Product Card:

- visual continuity روی image
- product hero وارد stage می‌شود
- title + price ظاهر می‌شود
- navigation context حفظ می‌شود

Fallback:
normal navigation + simple hero reveal.

---

# Section 01 — Product Hero

## Content
- name
- short description
- price
- key tags
- product image
- primary CTA / configuration start

## Layout
Desktop:
split یا art-directed center composition

Mobile:
image → content → controls

---

# Section 02 — Product Essence

یک statement کوتاه.

مثال:
`Double espresso, cold milk, and a soft caramel finish.`

هدف:
کاربر سریع بفهمد چه می‌خرد.

---

# Section 03 — Ingredient Narrative

## Visual
product pin optional

## Content
3–5 ingredient max

برای هر ingredient:
- name
- one short sentence
- optional image

Scroll sequence می‌تواند داشته باشد.

---

# Section 04 — Flavor Profile

نمایش ساده.

مثال:
- Creamy
- Sweet
- Bold

اگر intensity scale داریم، فقط در صورت واقعی بودن داده.

---

# Section 05 — Customization

این قسمت cinematic نیست.

## Groups

- Size
- Hot / Iced
- Milk
- Sweetness
- Extras

فقط optionهایی که برای محصول relevant هستند.

## UX

- default selection واضح
- price delta واضح
- unavailable disabled
- total price live update

---

# Section 06 — Add to Cart

Desktop:
می‌تواند sticky summary داشته باشد.

Mobile:
sticky bottom CTA می‌تواند مفید باشد.

محتوا:
- current price
- add to cart

---

# Section 07 — Product Story Optional

برای signature productها.

- origin
- process
- inspiration

برای همه محصول‌ها اجباری نیست.

---

# Section 08 — Related Products

حداکثر چند پیشنهاد مرتبط و باکیفیت.

مثلاً:
- same category
- complementary dessert
- similar flavor

---

# Section 09 — Delivery / Pickup Info

در صورت نیاز:
- availability
- selected location
- estimated pickup

---

# Reduced Motion

- no long pinned product
- ingredients static/stacked
- shared transition optional/disabled
- تمام محتوا بدون انیمیشن قابل دسترس
