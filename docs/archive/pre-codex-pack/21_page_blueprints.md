# 21 — Page Blueprints

---

# MENU

## Header
Title:
`Menu`

Optional short descriptor.

## Category Navigation
sticky only if useful.

## Product Grid
Card information:
- image
- name
- short descriptor
- price
- unavailable state
- quick action where valid

## Filters
فقط اگر Menu آنقدر بزرگ است که نیاز باشد.

برای کافه‌ی کوچک:
Category navigation کافی است.

## Motion
Low–medium.

---

# CATEGORY

Same foundation as Menu.

Additional:
- category hero tone
- category description max 1–2 lines

No cinematic intro unless category is campaign-like.

---

# PRODUCT DETAIL

## Above Fold
- image
- name
- short description
- price
- availability
- configuration start
- add to cart

## Story Layer
- ingredients
- flavor
- optional origin/story

## Conversion Layer
- customization
- price
- CTA

## Related
3–4 products.

---

# SEARCH

Prefer fast overlay or dedicated responsive route.

Elements:
- search input
- clear action
- recent query optional
- product results first
- category results
- journal results
- empty state

No decorative motion.
