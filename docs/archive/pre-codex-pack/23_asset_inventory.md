# Brand Assets

Required:
- logo primary

- wordmark if separate

---

# Per Product

Minimum:

1. Card image — 4:5
2. Hero image — 16:10
3. Detail image or ingredient close-up
4. Alt text
5. Optional isolated asset for motion

پس اگر N محصول داریم:

Minimum visual asset count:
`3 × N`

Optional motion-heavy collection:
`4 × N`
