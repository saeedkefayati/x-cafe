# 14 — Content Structure & Copy Framework

## هدف

قبل از نوشتن Copy نهایی، قالب محتوایی مشخص باشد.

---

# Home

## Hero

- Eyebrow optional
- Headline
- 1–2 line description
- Primary CTA
- Secondary CTA optional

## Product Transformation

برای هر state:

- Product name
- Short sensory phrase
- Optional price
- Optional 1–2 ingredient labels

## Category

- Category name
- Very short descriptor optional

## Brand Story

- 1 statement
- 1 short paragraph
- CTA

## Journal

- section title
- 2–3 post cards

## Location

- location name
- address
- hours summary
- visit CTA

---

# Product Detail

- Name
- Short description
- Price
- Ingredients
- Flavor notes
- Configuration labels
- Availability
- Optional story
- Related products

### Copy Rule

Product description بهتر است concrete باشد.

بد:
`یک تجربه فوق‌العاده و فراموش‌نشدنی.`

خوب:
`Double espresso, cold milk, ice, and a soft caramel finish.`

---

# Category Page

- Name
- Short category description
- Product count optional
- filters only if useful

---

# About

ساختار:

1. Brand statement

3. Craft/process
4. Sourcing or philosophy
5. Space/people

# Empty States

# Tone Rules

- جمله کوتاه
- adjective کم
- sensory detail واقعی
- ادعای بزرگ بدون evidence ممنوع
- اصطلاحات تخصصی فقط اگر کاربر می‌فهمد
