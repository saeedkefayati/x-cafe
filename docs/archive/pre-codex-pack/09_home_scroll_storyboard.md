# 09 — Home Scroll Storyboard

این Storyboard پایه است و هنگام طراحی نهایی ممکن است copy یا product تغییر کند.

---

# Section 01 — Hero

## هدف
اولین impression برند.

## Layout
- full viewport
- header minimal
- product hero center
- headline
- short subcopy
- primary CTA
- secondary CTA optional

## Motion

### 0–25%
- headline visible
- product stable
- subtle depth response

### 25–60%
- product slightly scales
- headline moves/fades
- supporting elements reduce

### 60–100%
- product transitions toward next narrative position
- next section theme enters

## Mobile
- no long pin
- shorter scale
- content immediately readable

---

# Section 02 — Product Transformation

## Concept
یک base drink به چند flavor/product تبدیل می‌شود.

مثال:
Espresso → Latte → Caramel Latte → Mocha

## Structure
- pinned visual stage
- product center
- product name
- small descriptor
- ingredient cards
- background theme

## Timeline

### State A — Espresso
- strong dark product
- coffee notes

### Transition A→B
- milk card enters
- background warms
- glass/cup visual changes
- name transitions

### State B — Latte
- creamy tone
- text updated

### Transition B→C
- caramel visual ingredient
- accent shifts

### State C — Caramel Latte

### Transition C→D
- cocoa/chocolate element

### State D — Mocha

## Rule
حداکثر 3–4 state.
بیشتر از آن خسته‌کننده می‌شود.

# Section 03 — Menu Categories

## هدف
بعد از cinematic opening کاربر وارد discovery واقعی شود.

## Layout
- large category labels
- category cards/images
- optional horizontal movement

## Interaction
Desktop:
vertical scroll driving horizontal movement فقط اگر UX روان باشد.

Mobile:
native horizontal swipe یا stacked cards.

# Home Global Rules

- cinematic sectionها پشت سر هم زیاد نباشند
- بعد از هر high-motion section یک breathing section
- CTA اصلی هر لحظه مشخص باشد
- mobile نسخه‌ی متفاوت، نه shrink شده‌ی desktop
- reduced-motion version کامل
