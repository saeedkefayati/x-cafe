# Historical archive

This directory preserves superseded planning and handoff material for traceability.

`pre-codex-pack` is the complete original planning package used before implementation began. Its files are intentionally preserved without rewriting.

Important:

- Do not treat archived files as current instructions.
- Start with `docs/ai/START_HERE.md` and `docs/ai/CONTEXT_MAP.md`.
- When archived and current documents conflict, current documents win.
- Use the archive only to understand historical rationale or recover detail not yet migrated into current documentation.
